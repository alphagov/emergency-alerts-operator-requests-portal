Automated log uploads

Uploading of CBC log files can be completed easily through the Operator Portal upload page by entering Mobile Operator and Broadcast ID details, and selecting your CBC log archive to upload. It is also possible to complete your upload directly from a command line, which will allow automated log uploads to be completed if this is preferred.

The URL to use for the upload can be constructed by adding the Mobile Operator identification code you have been allocated, and the unique Broadcast identification code for the logs you wish to upload (the UUID your CBC endpoint generated when accepting the broadcast request). As an example, assuming these details:

Mobile Operator identification code
T78QW4
Broadcast identification code
38c0d9e5-6782-4952-a11d-9097636f1f10

The corresponding upload URL would be:

https://operator-requests.emergency-alerts.service.gov.uk/log-upload?mno=T78QW4&broadcast_id=38c0d9e5-6782-4952-a11d-9097636f1f10

There are a number of tools which could be used to submit logs from the command line. As an example using cURL, and assuming a local zip archive of CBC logs called CBC-Log-Files.zip, the command line upload using the identification details above would be: 

curl --request PUT --upload-file CBC-Log-Files.zip 'https://operator-requests.emergency-alerts.service.gov.uk/log-upload?mno=T78QW4&broadcast_id=38c0d9e5-6782-4952-a11d-9097636f1f10'

Log file archive uploads must include logs from both the start and cancel operations, and must be completed within 2 days from the broadcast start time. Each Broadcast identification code allows only a single upload to be completed.
