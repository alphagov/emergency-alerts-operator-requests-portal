Automated log uploads

Uploading of CBC log files can be completed easily through the Operator Portal upload page by opening the link from your invite email and selecting your CBC log archive to upload. It is also possible to complete your upload directly from a command line, which will allow automated log uploads to be completed if this is preferred.

The upload URL is the exact link included in your invite email — it contains a unique, one-time upload token that identifies your broadcast and cannot be constructed or guessed from the Mobile Operator or Broadcast identification codes alone. As an example, if the link in your invite email were: 

https://operator-requests.emergency-alerts.service.gov.uk/upload-logs.html?token=Rl2f9K...

There are a number of tools which could be used to submit logs from the command line. As an example using cURL, and assuming a local zip archive of CBC logs called CBC-Log-Files.zip, the command line upload using the token from the link above would be: 

curl --request PUT --upload-file CBC-Log-Files.zip 'https://operator-requests.emergency-alerts.service.gov.uk/log-upload?token=Rl2f9K...'

Treat the upload token as a secret: anyone who obtains it can upload logs for your broadcast until it is used or expires. Do not share invite emails or forward upload links outside your organisation.

Log file archive uploads must include logs from both the start and cancel operations, and must be completed within 2 days from the broadcast start time. Each Broadcast identification code allows only a single upload to be completed.
