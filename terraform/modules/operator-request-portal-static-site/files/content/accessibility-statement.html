Accessibility statement for Operator Portal

This accessibility statement applies to the Operator Portal at operator-requests.emergency-alerts.service.gov.uk.

This service is run by the Department for Science, Innovation and Technology (DSIT). We want as many people as possible to be able to use this service, and it is built using the GOV.UK Design System.

AbilityNet has advice on making your device easier to use if you have a disability.

How accessible this service is

The upload form on this website needs JavaScript to work. If you cannot use the form, you can upload your logs from the command line instead, or contact us using the details below.

Feedback and contact information

If you need information on this service in a different format, or have any problems using it, contact Emergency Alerts Support at emergency-alerts-support@dsit.gov.uk.

We’ll consider your request and get back to you in 5 working days.

Reporting accessibility problems with this service

We’re always looking to improve the accessibility of this service. If you find any problems not listed on this page or think we’re not meeting accessibility requirements, contact Emergency Alerts Support at emergency-alerts-support@dsit.gov.uk.

Enforcement procedure

The Equality and Human Rights Commission (EHRC) is responsible for enforcing the Public Sector Bodies (Websites and Mobile Applications) (No. 2) Accessibility Regulations 2018 (the ‘accessibility regulations’). If you’re not happy with how we respond to your complaint, contact the Equality Advisory and Support Service (EASS).

Technical information about this service’s accessibility

DSIT is committed to making this service accessible, in accordance with the Public Sector Bodies (Websites and Mobile Applications) (No. 2) Accessibility Regulations 2018.

Compliance status

This website is fully compliant with the Web Content Accessibility Guidelines version 2.2 AA standard.

How we tested this service

This service was last tested on 18 November 2026. The Emergency Alerts team tested every page of the service, including the upload form when it shows errors, using the automated testing tools axe and HTML_CodeSniffer, which check pages against the Web Content Accessibility Guidelines (WCAG) AA standard. The team also tested the service manually using only a keyboard, with browser zoom up to 400%, and with the VoiceOver screen reader.

Preparation of this accessibility statement

This statement was prepared on 18 November 2026. It was last reviewed on 18 November 2026.
